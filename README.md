# Axleno Homebrew tap

```sh
brew install --cask callmecelebi/tap/bytewell
```

| Cask | App |
|---|---|
| `bytewell` | [Bytewell](https://bytewell.app): see what fills your Mac and safely get the space back. Developer and AI clutter, never deletes permanently. |

The cask is updated with every Bytewell release. Bytewell also updates itself (Sparkle), so `brew upgrade` isn't needed.
